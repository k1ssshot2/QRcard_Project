# :identification_card:QRcode_BusinessCard
## 🚀 소개
### 프로젝트 소개
 이 프로젝트는 QR 코드를 활용한 디지털 명함 안드로이드 앱 개발 프로젝트입니다. 사용자 별 고유 QR 코드를 생성해 스캔 시
이름, 이메일, 연락처 등 다양한 정보를 간단하고 빠르게 교환할 수 있습니다. 또한 디지털 명함이므로 내 정보를 수정할 시
자동으로 정보들이 업데이트되어 최신화된 정보를 확인 할 수 있습니다. 종이 명함을 대신해 불필요한 종이를 줄여 환경보호에서도
이점을 가질 수 있습니다.
